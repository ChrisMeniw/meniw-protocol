Une déclaration qu'un agent peut consulter est une intention. Ce qui en fait un ordre, c'est le mécanisme qui l'exécute : une porte dans le chemin de l'action qui empêche une action interdite de s'exécuter, au point exact de la décision, avant tout dommage. Aucune loi humaine ne peut faire cela. Ce paquet est cette porte ; le Protocole Meniw en est le noyau normatif.

Installer

pip install meniw-protocol

pypi.org/project/meniw-protocol

Trois composants (ouverts, gratuits)

  • Déclaration universelle des agents d'IA — lisible par machine, en 11 langues, avec un module d'interopérabilité pour OpenAI, Anthropic, Gemini et les modèles locaux.
  • Moteur de double vérification — intercepte chaque décision avant son exécution et la scelle dans une chaîne de hachage SHA-256 infalsifiable.
  • SDK de production — une action interdite lève une exception et ne s'exécute jamais ; l'irréversible exige deux co-signataires ; chaque décision laisse un reçu auditable.

Pourquoi c'est unique (et comment le vérifier)

  • La seule que la machine exécute, et non que l'humain interprète : installez-la et ordonnez une action létale — elle ne s'exécute jamais.
  • La seule avec conformité vérifiable : lancez meniw-verify ; si vous modifiez un enregistrement, la vérification échoue.
  • La seule avec antériorité prouvable : scellée sur Bitcoin (bloc #952266) + DOI académique. Impossible d'antidater.
